# Transcode
Settle which codecs Harbor actually produces, and rebuild the pipeline around that answer instead of around its history.

## What

The transcode pipeline grew one codec at a time and now supports a matrix nobody chose. This rock decides the matrix deliberately — which inputs are worth accepting, which outputs are worth producing, and what happens to everything already encoded the old way — and then reshapes the pipeline to match.

Done looks like a stated, defended codec matrix plus a pipeline that implements exactly it, with no branch surviving that the matrix does not name.

## Why now

Every added codec has made the on-the-fly session in [[F002 — On-the-Fly Transcode Session|F002]] harder to reason about, and the cost of the next one is rising. The retrospective ([[HBR R0001]]) will supply the usage numbers the matrix should be argued from — which is why this is scheduled behind it rather than beside it.

## Shape

- **Settle the codec matrix** — the decision itself, argued from the retrospective's numbers. In flight, and the slice named in `line::`.
- **Reshape the pipeline** — remove the branches the matrix does not name.
- **Decide the re-encode question** — what happens to the existing library. Possibly nothing.

Depends on [[HBR R0001]]. Touches [[HBR Ingest]] and [[F002 — On-the-Fly Transcode Session|F002]].
