# HBR - Harbor
A self-hosted media server that ingests, transcodes, and streams a personal library — the worked project-root example.


✂ ──── example notes ──── ✂

Nothing below this line is part of the example. Above it is a page that could sit in a real vault unchanged; below it is commentary about why it looks that way.

- **[[Clarifier]]** — a sibling project, so it belongs in `Related` rather than in a group row.
- **[[Devtools]]** — a grouped variant child anchor.
- **[[HBR Log]]** — a reverse-chronological container. It gets a plain row rather than a `+` group row because its members are dated entries, not named parts.
- **The `+` rows are what this example is for.** `Design+`, `Track+`, `User Docs+`, `Dev Docs+` and `Components+` each expand one sub-anchor's members inline, so the project root shows two levels at once. Twenty-two pages in the vault carry this shape; this is the worked one.
