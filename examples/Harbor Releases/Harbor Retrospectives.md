# Harbor Retrospectives
Every page that a Harbor release forced a change to — gathered by consequence, not by location.

> [!note] Canonical external spine
> A hub whose rows point at pages that are **deliberately not in its folder**. This page sits in `Harbor Releases/`, but nothing it lists does.
> - **It groups by a property, not by a place.** "Things a release forced a change to" cuts across the whole example set; no folder could hold that membership, which is exactly when this shape is right.
> - **It carries no marker, and that is part of the definition.** A `...` here would compute `Harbor Releases/`'s own dated children — the release pages — which is precisely the set this page is *not* about. The marker can only ever see the folder, so on a page that leaves the folder it is guaranteed to be wrong.
> - **Nothing can verify these rows.** Every other shape can be diffed against its folder; this one has no folder to diff against, so the rows are the author's word. That is the cost, and the reason to use it only when the grouping really is by property.
> - **Layout is independent.** This one happens to be grouped; an external spine could equally be a flat curated list.
>
> The live counterpart is [[STARTUPPER]]: thirty members whose pages sit all over `AT/`, gathered because they are startup-affiliated rather than because they share a directory.
