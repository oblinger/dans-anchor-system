# Bridges Air
The machine that leaves the house. It carries a full working copy and reconciles on return, so it is the only peer where a conflicted file is expected rather than alarming.

| Property | This machine |
|---|---|
| **Role** | edit anywhere, reconcile later |
| **Reachable** | when it is awake and on a network |
| **Holds** | a full Syncthing replica, no keys |
| **Rebuild cost** | an afternoon |

Listed by hand on [[Bridges]] rather than swept in by its catch-all — four machines is a small enough set that naming each one costs nothing and says more than a sorted list would.
