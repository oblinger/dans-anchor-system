# FEX
The examples pillar — you are on it. **FEX** is the page, not a forward to one, and the spine above is the whole index.

The **by-facet rows** carry the same eight groups as [[DAS Facets]], in the same order. Each entry displays the **facet name** and links to that facet's worked example, so clicking the facet name lands you on the example rather than on a page about the example. Extra examples for a facet follow in parens. An *italic, unlinked* entry is a facet with no example yet — a gap, deliberately visible. An italic entry marked **°** is not a gap: the entry is **not a facet spec** — either a *group page* enumerating member facets, or a *blueprint-level concept* — so it has no instances to exemplify (see § Gaps).

The **Worlds row** carries the fictional projects the in-context examples live inside: [[HBR|Harbor]], a media-server project with its own slug, holding a full tiny facet set; [[FEX Repo|Repo]], a fake skills repository tying the loose examples together; [[Knots]], a tiny Topic anchor; [[HWP|Harbor Whitepaper]], a Paper anchor; and [[CSE]], the fully-wired worked skill anchor. Worlds are where examples that are *not* à la carte live — the same corpus as the rows above, grouped the other way.

## How to read a cell

Under [[Tink327 - Every facet has a worked example, and FEX {facet} is how you reach it|F327]] Q1 **(A)**, a facet with one *à la carte* example resolves `FEX {facet}` to the example itself — [[FEX Agenda]] **is** the Agenda example, no index page in between. Most facets are not in that position: their example is an in-project document ([[HBR Backlog]]) or a live vault instance ([[Tink Backlog]], [[Disk Log]]), and the never-copy rule means `FEX {facet}` can only ever route to it. That is why the entries above link to a mixture of `FEX *`, `HBR *` and real anchors — the destination is wherever the example actually lives, which is the only place it should live.

When a second example arrives for a facet whose single example is à la carte, the incumbent moves to `FEX {facet} {qualifier}` and the bare name becomes the dispatch page. The bare name has become a **container**, so its contents need element names — the same rule that governs facet naming in [[DAS Facets]].

## Gaps and defects this index makes visible

Indexing by facet means a missing example has nowhere to hide. What the first pass surfaced, 2026-08-18:

**All nine "missing examples" are not facets, and the authoring queue is empty.** The first pass read `Anchor`, `Dispatch`, `Design Docs`, `Code`, `Doc` and `Output` as the broadest *facet* in each subsystem and concluded the general spec is simply the hardest to exemplify. Reading them settles it differently: each one's own opening line is a plural describing a family — *"The anchor & structure facets"*, *"the per-section sub-folder dispatch-page facets"*, *"The code facets"*, *"The doc facets"*. **A group page has no instances, so it cannot have a worked example, and its blank cell is correct rather than outstanding.**

That reading first left `Primitives` and `Aspects` as the real queue. **Neither survived it either.** `Primitives` carries the same `| Facets |` masthead as the six — it was filed under *Meta (proposed)* rather than a subsystem row, which is the only reason the first pass did not apply the test to it. `Aspects` is a blueprint-level concept page, and [[DAS Primitives]] rules it out in its own body: *"the deeper roots — anchor and aspect — are blueprint-level concepts … **not facet specs**."* So the queue went nine → two → zero, and the reason it kept collapsing is worth stating plainly: **"has no worked example" was never measuring exemplifiability — it was measuring whether the entry is a facet at all.**

The size gap makes it unarguable: **each of the six is 12–15 lines**, a masthead plus one sentence, while real facet specs beside them run 44 to 355. `DAS Anchor`'s entire body is *"The anchor & structure facets..."* — trailing ellipsis included — under frontmatter still claiming *"Defines an Anchor"*, so the page contradicts itself about which kind of thing it is. Three of the six also open with a doubled *"The the …"*, the signature of a generator concatenating `The ` onto a description that already began with `the`. Filed as [[Tink Backlog#^T365|T365]], because the fix is a ruling about the catalog rather than an example to author.

**`Dispatch Table Design` is its own example**, and says so: it records that it is *"the first worked instance of the minimal-facet capsule"* ([[FEX Minimal Facet]]). A design-rationale companion demonstrating the shape it documents needs no separate exemplar.

**Two more are stated-pending rather than forgotten** — `Changes` and `Specs` both record *"none yet — first adoption pending"* against the OpenSpec conversion, which is a gap with an owner and needs no action here.

**The four Skill-Anchor sub-facets are now named — and [[CSE]] was the wrong guess.** This paragraph previously read that CSE *"is almost certainly the example for all four."* It is not the example for any of them: CSE holds only markdown — no `config.yaml`, no `scripts/`, no `rules/`, no `tests/` — so it instantiates none of the four facets it was assumed to cover. Citing it would have produced exactly the vacuous coverage this feature's Success Criteria warns about, a checker going green on documents that demonstrate nothing. The real instances, found by looking for the artefact each facet describes rather than for a well-wired anchor: [[gshare skill|gshare]] (assets under `skills/`, config under `~/.config/anchor-system/`), [[audit]] (the largest conformant `scripts/`), [[Find Skill|find]] (`rules/` defaults plus `SRCH rules/` overrides), and [[ctrl skill|ctrl]] — which is the **only** skill in the repo whose `tests/` carries the `unit/`+`live/` split its own facet spec leads with.

**`Stone` was citing Rocks documents, and now spans both kinds.** The row held [[HBR Rocks]] and [[MED Rocks]] — two instances of one kind, the first of them also [[DAS Rocks]]' own example. A facet whose whole claim is *"one shape parameterised by kind"* cannot show that with two examples of the same kind. Adjudicated: Stone keeps a Rocks instance and gains ~~[[Lumen Pebbles]]~~, the control file of a Pebbles group, so the pair spans the parameter the facet exists to express.

**`Move` cited its own facet spec as its example.** The row read `[[DAS Move|skill runbook]]`, which after the [[Tink Backlog#^T339|T339]] renames resolves to the facet spec itself rather than to a worked instance. This index links [[SKA move]] instead — the managing anchor, which is a real instance.

**Twelve facet specs claimed two examples where one document exists**, citing the same target twice under two labels (`[[HBR Design|minimal]], [[HBR Design|fuller]]`). Corrected at the specs 2026-08-18; the second example in each of those twelve is a genuine gap, now visible above as a facet with a single entry.
