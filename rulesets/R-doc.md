description:: Everything checked when auditing a document — markdown + file + dispatch-table conventions plus the doc-facet rulesets (Doc Structure, Ruleset, Brief, Discussion, Log, Messages, Query, Backlog) and the design-doc facet rulesets (PRD, Architecture, Testing, Decisions, Stories).

The umbrella that **`/audit doc <path>`** resolves ([[F001 — Rule-driven audit engine — resolve, run, judge|F001]]) — and, since the doc-fire rides it, the rule set every anchored markdown write is checked against. The convention sets (`R-markdown`, `R-file-association`, `R-dispatch-table`) apply to every document (`always` / every-md `where::`); the facet sets fire only on their `where::` targets — `R-doc-structure` on every authored doc, a `# RULESET` block → `R-ruleset`, a `# BRIEF` → `R-brief`, a Discussion heading → `R-discussion`, a `* Log.md` → `R-log`, a `* Messages.md` → `R-messages`, a `* Backlog.md` → `R-backlog`, a `* PRD.md` → `R-prd`, a `* Architecture.md` → `R-architecture`, a `* Testing.md` → `R-testing`, a `* Decisions.md` → `R-decisions`, a `* Stories.md` / `US-*.md` → `R-stories`, a `* System Design.md` → `R-fct-system-design` (added 2026-08-05, Q004 — the set had a dead `where::` glob AND no adoption, two independent reasons it had never fired; re-derived from instances and armed with the blast radius measured first: 7 of 14 instances fail R-01 on the known pre-F142 `{slug} Track/` lag, 2 fail R-05, 0 unexpected), a `facets/DAS *.md` facet spec → `R-facet-spec` (added 2026-07-13, T014 — authored trait-scoped but never included here, so it had been dormant since authoring). The per-rule `where::` selector does the binding, so an included ruleset only fires on its own file kind. Add a doc facet's ruleset to the `include::` line to bring it into `/audit doc`. (`R-dispatch-table` added 2026-07-06, Warden T008 — the SKL Query trio showed masthead-row rules authored but active only at `/audit anchor`, so nothing fired on write. `R-naming` stays audit-only: a 2026-07-06 activation attempt measured 376 fails in dans-anchor-system alone — catalog-prefix files (then DSC/FCT/FEX/SKL) under anchors with undeclared slugs — so on-write naming waits on the catalog-slug/allowlist decision, Warden T009.)
