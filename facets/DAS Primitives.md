# Primitives
The primitives — the reflexive facets that define the kinds of authored object the dans-anchor-system system is built from.

## Overview
These facets are **reflexive** — each defines one of the *kinds of thing you author in this system*, rather than a document shape a project's content takes. A [[DAS Skill|skill]] is an invocable verb; a [[DAS Facet|facet]] is a narrow file/region aspect; a [[DAS Disciplines|discipline]] is a behavioral practice the agent reads; a [[DAS Ruleset|ruleset]] is a declarative-constraint block; a [[DAS Traits|trait]] is a broad anchor paradigm declared in `traits:`. Together they are the system's own vocabulary — the metamodel the other facet groups (Anchor / Design / Track / Output / Doc) are described in terms of.

Skill, Facet, and Trait line up with the repo pillars (`skills/` `facets/` `disciplines/` `library/`); Ruleset is the library's ruleset kind. The deeper roots — *anchor* and *aspect* — are blueprint-level concepts (see [[DAS Anchor Tree]] / [[DAS Aspects]]), not facet specs, so they live in the library rather than here.

*Discipline and Trait still link to their pre-migration `CAB <X>` specs (SKA Roadmap M1 moves them to DSC / the library); the links update from-there when those land.*
