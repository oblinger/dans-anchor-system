# imail — Access Methods (retired 2026-08-11 → redirect)

**This card is retired. Its job moved to [[io/SKILL]]'s Actions table.** The file stays as a redirect stub so existing wiki-links keep resolving — the same treatment `Office Equipment.md` got when it folded into [[My Stuff Computer]].

**Why it went.** This page existed to compare *how* to reach mail when there was one working surface and two aspirational ones. There are now three real surfaces, each with its own contract, and Dan's call (2026-08-11) was to keep them **explicit** rather than behind a router: *"the agent can be explicit about what they want the system to do."* A separate comparison page then does harm — it makes an agent read two files to answer one question, and it is a second place for the routing facts to drift out of date.

**Where each thing lives now:**

| You want | Go to |
| --- | --- |
| Drive Apple Mail — every configured account, **and the only way to send** | [[io-imail]] |
| Search the fast local index — all mirrored accounts at once, offline, read-only | [[io-local-mail]] |
| Gmail's servers — one account's full history, ~1 s | [[io-gmail]] |
| Which surface for which question | [[io/SKILL]] § Actions |
| Which accounts exist and which are mirrored | [[Emails]] |
| How the local mirror is wired, installed and credentialed | [[WIRE Mail Local Index]] |

**The one routing fact worth repeating anywhere:** `dan@sportsvisio.com` **cannot** be reached by [[io-gmail]] — the org disabled Gmail API access. Use [[io-imail]] or [[io-local-mail]]. That constraint is why the local mirror was built at all.
